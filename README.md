# One Word for Your Wi-Fi

One word describing home Wi-Fi — written to win the funniest-and-truest
judge. Entry for the
[One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72)
bounty on [make.fun](https://make.fun/r/kgxbmb08).

## The word

> Peekaboo

Why it works, against the judge's brief:

1. **On-subject** — it names exactly how home Wi-Fi behaves: there one
   second, gone the next, back again before you can complain.
2. **Funny at once** — a childhood game everyone knows, no pun to decode;
   the laugh lands the instant you read it.
3. **True** — every home has the dead spot by the bedroom door, the bars
   that vanish mid-call, the router that hides when guests arrive.
4. **Fresh** — the crowd reaches for "slow", "laggy", "ghost" or
   "buffering"; nobody names the game the signal is playing.
5. **One word, eight letters** — spelled exactly as it sounds, and it
   works as a network name on its own.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Deterministic — two runs from different working directories write
byte-identical `entry.txt` (8 characters). The program writes only to
the absolute path in `MAKEFUN_OUTPUT_DIR`; the grader runs the repo
read-only, so there is no relative-path write anywhere.
